# CarbonCap — บรีฟปรับดีไซน์

สถานะ: สร้างตามคอนเซปต์ 4 หน้าผ่าน TokenMe แล้ว ผู้ใช้ขอเอาคำที่ทำให้รู้สึกเป็น prototype เช่น ทดลอง/จำลอง ออกจากหน้าตาแอป ซึ่งเปลี่ยนเป็นภาษาของแอปเรียบร้อย

## สิ่งที่ผู้ใช้ยืนยัน

- ปรับหน้าตาเว็บโดยอ้างอิงเว็บไซต์ GreenLife ในภาพที่แนบ 3 ภาพ
- ธีมสี: เขียว ฟ้า ขาว
- เก็บความสามารถของเครื่องมือเดิม แต่จัดเป็นแอปที่แยกหน้าหรือขั้นตอนตามงาน โดยหน้าแรกให้เลือกโครงการก่อน
- ใช้ภาพวาด flat ใหม่สำหรับ CarbonCap เช่น เกษตรกร โลก และดาวเทียม เป็นภาพนำ และใช้ภาพ GEE จริงในส่วนเครื่องมือ
- การเคลื่อนไหวเบา ๆ เน้นอ่านง่ายและกดลื่น
- วางภาพวาดในแถบต้อนรับขนาดกระชับด้านบนของหน้าเลือกโครงการ
- ใช้การ์ดภาพ 3 โครงการแบบโปร่ง กดแล้วเปิดรายละเอียดและเครื่องมือของโครงการที่เลือก
- การจัดหน้าต้องแยกแต่ละงานหรือส่วนให้ชัด เพิ่มพื้นที่ว่างและลดความรู้สึกว่าข้อมูลวางติดกันแน่น
- ปุ่มและองค์ประกอบต้องมีขอบโค้งและเงาที่สร้างมิติ ให้รู้สึกลอยออกจากพื้น พร้อมการตอบสนองเมื่อกด

## การจัดหน้าที่ตกลงใหม่

- ย้ายแผนที่ไปหลังการเลือกโครงการ แทนข้อตกลงก่อนหน้าที่ต้องเห็นแผนที่ในจอแรก
- หน้าแรกเน้นเลือกโครงการจากการ์ด เครื่องมือแสดงเมื่อเข้าสู่โครงการนั้น
- รายละเอียดสี ภาพวาด การ์ด 3 โครงการ และ motion เบา ๆ ยังใช้ตามเดิม

## สเปกภาพรวมที่ยืนยันแล้ว

- แถบนำทางพื้นขาว: ชื่อ CarbonCap พร้อมเมนูสำรวจโครงการและพอร์ตจำลอง
- พื้นขาวเป็นหลัก ตัวอักษรสีเขียวเข้ม ปุ่มและไฮไลต์สีเขียว พื้นประกอบฟ้าอ่อน และพื้นที่ว่างโปร่งแบบภาพอ้างอิง
- หน้า 1 — สำรวจโครงการ: แถบต้อนรับกระชับ หัวข้อใหญ่ ภาพวาด flat แนวเกษตรกร โลก และดาวเทียม ตามด้วยตัวกรองและการ์ด 3 โครงการ พร้อมพื้นที่ว่างระหว่างส่วนชัดเจน
- หน้า 2 — รายละเอียดโครงการ: มีทางกลับหน้าเลือกโครงการ แสดงข้อมูลสำคัญของโครงการ และแยกภาพดาวเทียมกับผลวิเคราะห์ AI เป็นแท็บ เพื่อดูทีละงาน มีทางไปซื้อจำลองหรือติดตามตามสถานะ
- หน้า 3 — ซื้อจำลอง: กรอกจำนวน ดูมูลค่า ตรวจทาน แล้วกดยืนยันซื้อ โดยไม่วางฟอร์มซื้อรวมในหน้าแผนที่
- หน้า 4 — พอร์ตจำลอง: ดูยอดถือครอง มูลค่าที่จ่าย ประวัติ และรายการติดตาม พร้อมรีเซ็ตข้อมูลจำลอง
- การ์ดโครงการ 3 ใบใช้ภาพพื้นที่จริง ชื่อและจังหวัดเด่น แสดงสถานะ จำนวนเครดิต และราคาจำลองอย่างอ่านง่าย พร้อมตัวกรองเดิม
- พอร์ตจำลองใช้ภาษาภาพเดียวกัน จัดการถือครองและประวัติให้อ่านง่าย
- ปุ่มทรงแคปซูลและการ์ดขอบโค้ง ใช้เงานุ่มเพื่อสร้างระดับชั้น ปุ่มมี feedback เมื่อกด และเนื้อหาปรากฏแบบเบา ๆ รองรับ reduced motion
- บนมือถือจัดเป็นคอลัมน์เดียว ปุ่มหลักอย่างน้อย 44px และไม่มีการล้นแนวนอน
- คง flow เดิม: เลือกโครงการ → ดูภาพและหลักฐาน → วิเคราะห์จำลอง → คำนวณและตรวจทาน → ซื้อจำลอง → พอร์ต รวมการติดตาม การบันทึก และรีเซ็ต
- การเปลี่ยนหน้าและปุ่มย้อนกลับต้องชัดเจน โดยใช้มุมมองต่าง ๆ ภายใน HTML ไฟล์เดิม และเก็บข้อมูลจำลองเดิมในเบราว์เซอร์ต่อได้
- ใช้ภาพคอนเซปต์เป็นสเปกก่อนส่งให้ DeepSeek แก้โค้ดผ่าน TokenMe จากนั้นตรวจภาพและ flow ก่อนอัปเดต GitHub Pages เดิม

## รอบภาพคอนเซปต์

- สร้างครบ 4 ภาพและผู้ใช้อนุมัติให้เริ่มสร้างแล้ว
- ภาพที่ส่งให้พิจารณาอยู่ใน `design/concepts/v2/`: `01-discover.png`, `02-project.png`, `03-purchase.png`, `04-portfolio.png` และบันทึก prompt กับแหล่งไฟล์ใน `concept-manifest.json`
- ภาพเหล่านี้เป็นภาพจำลองดีไซน์สำหรับกำหนดการจัดหน้า เมื่อลงโค้ดต้องใช้ภาพ GEE ต้นฉบับเดิม ตัวอักษรและปุ่มจริงที่ใช้งานได้
- ใช้ imagegen แบบ built-in สร้างภาพแต่ละหน้าขนาดอ่านรายละเอียดได้ และใช้ภาษาภาพเดียวกันทั้งชุด
- หน้าเลือกโครงการ: พื้นขาวโปร่ง แถบภาพวาดกระชับ การ์ดภาพ 3 โครงการ และตัวกรอง
- หน้ารายละเอียด: แผนที่และแท็บ AI แยกงานชัด ปุ่มไปซื้อจำลองเด่น พร้อมทางย้อนกลับ
- หน้าซื้อจำลอง: ตัวอย่างซื้อ 10 เครดิตของแม่ริม ราคา 650 บาทต่อเครดิต รวม 6,500 บาท พร้อมขั้นตรวจทาน
- หน้าพอร์ต: ตัวอย่างถือครอง 10 เครดิตแม่ริม มูลค่าที่จ่ายจำลอง 6,500 บาท และรายการติดตามปากช่อง
- ภาพคอนเซปต์ใช้เพื่อพิจารณาหน้าตาและการจัดวาง การสร้างโค้ดและเผยแพร่จะเริ่มหลังผู้ใช้เลือกคอนเซปต์

## คำในแอปที่ผู้ใช้ขอปรับหลังอนุมัติภาพ

- ใช้ชื่อเมนู “พอร์ตของฉัน” และข้อความ “ซื้อคาร์บอนเครดิต”, “ตรวจทานรายการ”, “บันทึกเข้าพอร์ต”, “ล้างข้อมูลพอร์ต” แทนคำว่าทดลอง/จำลอง/ต้นแบบ
- ตัดแถบประกาศยาวและวงเล็บที่ย้ำสถานะ prototype ออกจากส่วนหลัก
- คงข้อความข้อเท็จจริงสั้นเฉพาะจุด: คาร์บอนเป็นค่าประเมิน, NDVI ไม่วัดคาร์บอนโดยตรง, ต้องตรวจรับรองก่อนออกเครดิต, ระบบยังไม่รับชำระเงิน และรายการที่บันทึกไม่ใช่ใบรับรองเครดิต
- ไม่เพิ่มการชำระเงิน การออกเครดิตจริง หรือเปลี่ยนข้อมูลดาวเทียม/คาร์บอน/โครงการจากเดิม
- ภาพ production แยกอยู่ที่ `design/assets/` พร้อม prompt ใน manifest; ใช้ฟอนต์ Noto Sans Thai ที่ฝังใน HTML และเก็บ OFL license

## ผลงานที่สร้าง

- แยกหน้าเลือกโครงการ รายละเอียด ซื้อ และพอร์ตภายใน HTML ไฟล์เดียว ใช้แท็บภาพดาวเทียม/ประเมินคาร์บอนในรายละเอียด
- ภาพ GEE ต้นฉบับ 6 ภาพยังตรงตาม SHA-256 เดิม ภาพวาด 3 ภาพและฟอนต์ฝังใน HTML ไม่มีการโหลดทรัพยากรภายนอกขณะใช้งาน
- เก็บ localStorage key และ schema เดิม ใช้รายการเดิมต่อได้
- ตรวจผ่าน in-app browser บนเดสก์ท็อปและมือถือ รวม flow และตัวกรอง การประเมิน การบันทึกพอร์ต การติดตาม การยกเลิกและการล้างข้อมูล
- รูปคอนเซปต์ยังเก็บข้อความก่อนขอแก้คำไว้เป็นหลักฐานอ้างอิง ส่วนแอปใช้ข้อความที่ผู้ใช้ขอปรับแล้ว

## ข้อตกลงเดิมที่ใช้ประกอบการออกแบบ

- ภาษาไทยเป็นหลัก และผลงาน HTML ไฟล์เดียวที่เปิดออฟไลน์ได้
- ภาพดาวเทียมและ NDVI จริงจาก Google Earth Engine; ผลคาร์บอน โครงการ ราคา และการซื้อเป็นข้อมูลจำลอง
- ให้ DeepSeek เขียนและแก้โค้ดผ่าน TokenMe โดย Codex เตรียมบรีฟและตรวจรับ
- Repository หลัก CarbonCap เป็น Private; ใช้ CarbonCap-pages แบบ Public สำหรับเผยแพร่ไฟล์เว็บบน GitHub Pages
- การเปลี่ยนแปลง flow เดิมต้องระบุชัดในสเปกที่ยืนยันก่อนเริ่มสร้าง
