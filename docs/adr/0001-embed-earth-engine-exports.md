# ฝังผลส่งออกจาก Google Earth Engine เพื่อเปิดต้นแบบออฟไลน์

CarbonCap เลือก Google Earth Engine เป็นแหล่งภาพดาวเทียม แต่ต้นแบบต้องเป็น HTML ไฟล์เดียวที่เปิดออฟไลน์ได้ จึงใช้ Earth Engine เฉพาะขั้นเตรียมข้อมูล แล้วฝังภาพและชั้นข้อมูลที่ส่งออกพร้อมแหล่งที่มาและช่วงวันที่ไว้ใน HTML แทนการเรียก API ขณะใช้งาน การตัดสินใจนี้รักษาประสบการณ์ออฟไลน์ โดยยอมให้ภาพเป็นข้อมูล ณ ช่วงเวลาที่บันทึกและมีขอบเขตพื้นที่จำกัด; ผลประเมินคาร์บอนและธุรกรรมในต้นแบบยังเป็นข้อมูลจำลอง
