# ใช้ repository สาธารณะแยกสำหรับ GitHub Pages

ผู้ใช้ต้องการเว็บไซต์สาธารณะและเก็บ repository หลัก CarbonCap เป็น Private แต่ GitHub ปฏิเสธการเปิด Pages จาก repository ส่วนตัวบนแผนบัญชีปัจจุบัน ผู้ใช้จึงอนุญาตให้สร้าง CarbonCap-pages แบบ Public สำหรับ index.html และ .nojekyll เท่านั้น โดยเผยแพร่จาก branch codex/github-pages ส่วนโค้ดต้นทางและเอกสารใน repository หลักยังเป็น Private การอัปเดตแอปจึงต้องอัปเดตไฟล์ใน repository เผยแพร่ด้วย
