# CarbonCap

CarbonCap เป็นเว็บแอป HTML ไฟล์เดียวสำหรับสำรวจโครงการเกษตรผ่านภาพดาวเทียมจริงจาก Google Earth Engine ดูค่าประเมินคาร์บอน และบันทึกรายการเครดิตในพอร์ต ทุกอย่างรันในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์หรือการชำระเงินจริง

ดีไซน์ปัจจุบันใช้เขียว–ฟ้า–ขาว ภาพวาดประกอบ พื้นที่ว่างโปร่ง การ์ดขอบมน และปุ่มแคปซูล แยกเป็น 4 หน้าตามงาน: เลือกโครงการ → รายละเอียด → ซื้อ → พอร์ต ภาพวาดและฟอนต์ Noto Sans Thai ถูกฝังใน HTML พร้อมภาพ GEE ทั้ง 6 ภาพ

## เว็บออนไลน์

- [เปิด CarbonCap บน GitHub Pages](https://matchagtea.github.io/CarbonCap-pages/)
- Repository หลัก `MatchaGtea/CarbonCap` เป็น Private
- [CarbonCap-pages](https://github.com/MatchaGtea/CarbonCap-pages) เป็น Public สำหรับเผยแพร่เฉพาะ `index.html` และ `.nojekyll` จาก branch `codex/github-pages`
- เมื่อแก้แอปใน repository หลัก ต้องนำ `index.html` รุ่นล่าสุดไปอัปเดต repository เผยแพร่ด้วย

## วิธีเปิดใช้งาน (ออฟไลน์)

1. ดาวน์โหลดไฟล์ `index.html` ไฟล์เดียว
2. เปิดด้วยเบราว์เซอร์ (ดับเบิลคลิกหรือลากเข้าแท็บเบราว์เซอร์)
3. ไม่ต้องติดตั้ง ไม่ต้อง build ไม่ต้องมีอินเทอร์เน็ต — ภาพและโค้ดทั้งหมดถูกฝังอยู่ในไฟล์เดียวแล้ว

> หมายเหตุ: ไฟล์ `index.html` มีขนาดใหญ่ (ภาพถูกฝังเป็น base64) จึงเหมาะเปิดโดยตรงจากเครื่องมากกว่าการแก้ไขด้วยมือ

## ฟลอว์การใช้งานหลัก

- **เลือกโครงการ** — เลือกการ์ดแม่ริม / ท่าใหม่ / ปากช่อง ค้นหาด้วยชื่อ จังหวัด หรือชนิดพืช และกรองพร้อมซื้อ / กำลังประเมิน
- **รายละเอียดโครงการ** — สลับแท็บภาพดาวเทียมกับประเมินคาร์บอน ดู RGB / NDVI / คาร์บอน พร้อมวันที่ แหล่งที่มา และวิธีประเมิน
- **ซื้อคาร์บอนเครดิต** — เลือกจำนวน ดูมูลค่า ตรวจทาน แล้วยืนยันบันทึกเข้าพอร์ต ระบบยังไม่รับชำระเงินและรายการไม่ใช่ใบรับรองเครดิต
- **พอร์ตของฉัน** — ดูเครดิต มูลค่าที่บันทึก การถือครอง ประวัติรายการ และโครงการที่ติดตาม ข้อมูลพอร์ตเดิมยังใช้ต่อได้
- **ล้างข้อมูลพอร์ต** — ยืนยันก่อนล้างรายการและการติดตาม พร้อมคืนจำนวนเครดิตของโครงการ

## ภาพจริง vs ข้อมูลจำลอง

- **ภาพ RGB/NDVI เป็นข้อมูลจริง** — มาจากดาวเทียม Sentinel-2 (ชุดข้อมูล `COPERNICUS/S2_SR_HARMONIZED`) ที่ประมวลผลผ่าน Google Earth Engine ดูรายละเอียดที่ [docs/imagery-provenance.md](docs/imagery-provenance.md) และ [docs/gee-manifest.json](docs/gee-manifest.json)
- **ชื่อโครงการ ขอบเขตแปลง พื้นที่ การประมาณคาร์บอน ราคา และธุรกรรมเป็นการจำลอง** เพื่อการสาธิตเท่านั้น
- **การประมาณคาร์บอนด้วย AI ไม่ใช่เครดิตที่ออกจริง** และ NDVI เป็นดัชนีพืชพรรณ ไม่ใช่การวัดคาร์บอนโดยตรง

## การจัดเก็บข้อมูล

- ข้อมูลพอร์ตและรายการติดตามถูกเก็บไว้ใน **localStorage ของเบราว์เซอร์** (เฉพาะเครื่องของคุณ) ไม่มีการส่งข้อมูลออกจากเครื่องและไม่มีการทำธุรกรรมจริง
- พฤติกรรมการจัดเก็บของไฟล์ที่เปิดผ่าน `file://` แตกต่างกันตามเบราว์เซอร์ แอปจะตรวจจับและจัดการความล้มเหลวโดยเก็บข้อมูลในหน่วยความจำสำหรับเซสชันนั้นแทน

## คุณภาพและการทดสอบ

- ตรวจใน in-app browser ที่ desktop 1513×1039 และ mobile 390×844: การค้นหา/กรอง แท็บและชั้นภาพ การประเมินคาร์บอน จำนวนเครดิตที่ไม่ถูกต้อง การตรวจทาน/ยืนยัน/ยกเลิก พอร์ต การติดตาม การรีโหลด การย้อนกลับ และล้างข้อมูลผ่าน ไม่มีข้อผิดพลาดใน console ที่ตรวจ
- เทียบภาพทั้ง 4 หน้ากับคอนเซปต์ที่อนุมัติ ตรวจสี ตัวอักษร ระยะ การ์ด ปุ่ม ไอคอน และภาพประกอบ พร้อมแก้หน้าซื้อที่ล้นและช่องค้นหาบนมือถือที่สูงเกินไป
- ตรวจ syntax JavaScript, SHA-256 ภาพ GEE 6 ภาพ, ภาพวาด 3 ภาพ และฟอนต์ที่ฝัง ไม่มี external runtime resources
- การตรวจ QA ดำเนินการผ่าน **localhost** เนื่องจากเบราว์เซอร์ทดสอบบล็อกการเปิด `file://` — จึงยัง**ไม่มีการทดสอบการเปิดไฟล์ `file://` โดยตรง** และไม่ได้อ้างว่าแอปผ่านการทดสอบในทุกเบราว์เซอร์

## สร้างไฟล์ HTML ใหม่

แก้ source ขนาดเล็กที่ `.build-inputs/index-source.html` แล้วรัน `python3 .build-inputs/rebuild_html.py` เพื่อฝังภาพ GEE ภาพวาด และฟอนต์ ก่อนตรวจไฟล์ `index.html` อัตโนมัติ ไม่ควรแก้ base64 ในไฟล์ปลายทางด้วยมือ

ภาพวาดสร้างด้วย built-in imagegen มี prompt และไฟล์ต้นทางใน `design/assets/manifest.json` ฟอนต์ Noto Sans Thai ใช้ SIL Open Font License ซึ่งเก็บใน `design/assets/fonts/OFL.txt`
