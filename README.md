# CarbonCap

CarbonCap เป็นเว็บแอปแบบหน้าเดียว (single-file) ที่ใช้สำรวจโครงการเกษตรตัวอย่างผ่านภาพดาวเทียมจริงจาก Google Earth Engine พร้อมเครื่องมือจำลองการซื้อเครดิตคาร์บอน โดยทุกอย่างรันในเบราว์เซอร์ของคุณ ไม่มีเซิร์ฟเวอร์หรือการชำระเงินจริง

## วิธีเปิดใช้งาน (ออฟไลน์)

1. ดาวน์โหลดไฟล์ `index.html` ไฟล์เดียว
2. เปิดด้วยเบราว์เซอร์ (ดับเบิลคลิกหรือลากเข้าแท็บเบราว์เซอร์)
3. ไม่ต้องติดตั้ง ไม่ต้อง build ไม่ต้องมีอินเทอร์เน็ต — ภาพและโค้ดทั้งหมดถูกฝังอยู่ในไฟล์เดียวแล้ว

> หมายเหตุ: ไฟล์ `index.html` มีขนาดใหญ่ (ภาพถูกฝังเป็น base64) จึงเหมาะเปิดโดยตรงจากเครื่องมากกว่าการแก้ไขด้วยมือ

## ฟลอว์การใช้งานหลัก

- **สำรวจโครงการ** — เลือกภูมิภาค (แม่ริม / ท่าใหม่ / ปากช่อง) เพื่อโหลดภาพ RGB หรือ NDVI จริงจาก GEE สลับชั้นคาร์บอนจำลองได้
- **ค้นหา/กรอง** — ค้นหาด้วยชื่อ/จังหวัด/ชนิดพืช และกรองสถานะโครงการ (พร้อมซื้อขาย / รอตรวจสอบ)
- **วิเคราะห์ AI (จำลอง)** — กด "ทดลองวิเคราะห์ AI" เพื่อแสดงประมาณการคาร์บอนรายปีแบบจำลอง
- **ซื้อเครดิต (จำลอง)** — กรอกจำนวน ตรวจทานใน dialog แล้วยืนยัน ระบบจะลดเครดิตพร้อมซื้อของโครงการ เพิ่มเครดิตในพอร์ต และบันทึกประวัติธุรกรรม
- **พอร์ตจำลอง** — ดูเครดิตสะสม มูลค่าที่จ่าย การถือครอง ประวัติธุรกรรม และโครงการที่ติดตาม
- **รีเซ็ตข้อมูลจำลอง** — ล้างพอร์ต รายการติดตาม และคืนยอดเครดิตของโครงการทั้งหมด

## ภาพจริง vs ข้อมูลจำลอง

- **ภาพ RGB/NDVI เป็นข้อมูลจริง** — มาจากดาวเทียม Sentinel-2 (ชุดข้อมูล `COPERNICUS/S2_SR_HARMONIZED`) ที่ประมวลผลผ่าน Google Earth Engine ดูรายละเอียดที่ [docs/imagery-provenance.md](docs/imagery-provenance.md) และ [docs/gee-manifest.json](docs/gee-manifest.json)
- **ชื่อโครงการ ขอบเขตแปลง พื้นที่ การประมาณคาร์บอน ราคา และธุรกรรมเป็นการจำลอง** เพื่อการสาธิตเท่านั้น
- **การประมาณคาร์บอนด้วย AI ไม่ใช่เครดิตที่ออกจริง** และ NDVI เป็นดัชนีพืชพรรณ ไม่ใช่การวัดคาร์บอนโดยตรง

## การจัดเก็บข้อมูล

- ข้อมูลพอร์ตและรายการติดตามถูกเก็บไว้ใน **localStorage ของเบราว์เซอร์** (เฉพาะเครื่องของคุณ) ไม่มีการส่งข้อมูลออกจากเครื่องและไม่มีการทำธุรกรรมจริง
- พฤติกรรมการจัดเก็บของไฟล์ที่เปิดผ่าน `file://` แตกต่างกันตามเบราว์เซอร์ แอปจะตรวจจับและจัดการความล้มเหลวโดยเก็บข้อมูลในหน่วยความจำสำหรับเซสชันนั้นแทน

## คุณภาพและการทดสอบ

- การตรวจ QA ดำเนินการผ่าน **localhost** เนื่องจากเบราว์เซอร์ทดสอบบล็อกการเปิด `file://` — จึงยัง**ไม่มีการทดสอบการเปิดไฟล์ `file://` โดยตรง** และไม่ได้อ้างว่าแอปผ่านการทดสอบในทุกเบราว์เซอร์
